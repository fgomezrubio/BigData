## 🧠 Descripción de la Actividad

Esta actividad tiene como objetivo aplicar técnicas de **aprendizaje supervisado** y **no supervisado** a un conjunto de datos de criptomonedas, utilizando herramientas de Big Data. Se utilizaron algoritmos como RandomForest clustering (K-Means), evaluando su desempeño con métricas específicas y visualizaciones gráficas.
